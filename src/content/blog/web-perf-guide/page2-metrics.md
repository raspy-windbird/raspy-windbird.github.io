## Core Web Vitals

Google が推奨する三つの指標：

### LCP (Largest Contentful Paint)
ページ内で最も大きいコンテンツが表示される時間。目標は2.5秒以下です。

### FID (First Input Delay)
ユーザーの最初のインタラクションに対するレスポンス時間。目標は100ms以下です。

### CLS (Cumulative Layout Shift)
ページの予期しないレイアウトシフトの合計。目標は0.1以下です。

次のページでは、これらの指標を改善するための実践的なテクニックを紹介します。
